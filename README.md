# Titanic Survival Analysis

A beginner data analysis project exploring what factors influenced passenger survival on the Titanic, using the classic Kaggle Titanic dataset.

## Tools Used
- Microsoft Excel / Google Sheets (Pivot Tables, Formulas, Charts)

## Dataset
[Titanic - Machine Learning from Disaster (Kaggle)](https://www.kaggle.com/c/titanic/data)

## Process
- Cleaned and explored the dataset using basic formulas (COUNTA, COUNTBLANK, AVERAGE)
- Built Pivot Tables to calculate survival rate by Gender, Passenger Class, and Age Group
- Created bar and line charts to visualize the trends
- Summarized findings in plain English

## Key Findings
- Women had a much higher survival rate than men (74.20% vs 18.89%)
- 1st class passengers survived far more often than 3rd class passengers (62.96% vs 24.24%)
- Children had the highest survival rate (53.98%), while Seniors had the lowest (26.92%) — age mattered, but not in a simple straight line
- Overall, gender and ticket class appear to be the strongest factors in survival
